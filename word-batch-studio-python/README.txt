WORD BATCH STUDIO PRO - PYTHON VERSION

HOW TO RUN
1. Microsoft Word must already be installed.
2. Python 3 must be installed and allowed by your PC/IT policy.
3. Run INSTALL_DEPENDENCY.bat once to install pywin32.
4. Then run RUN_APP.bat.

You can also run directly:
    py Word_Batch_Studio_Pro.py

FEATURES
- Batch edit many Word files
- Multiple Find/Replace boxes
- Add/remove rules
- Words, sentences and paragraphs
- Main body, headers, footers, text boxes, notes/comments
- Image replacement
- Separate Edited Documents output folder
- Originals remain untouched
- Save/load rule sets
- Protection/content-control options
- CSV processing report

SECURITY
This package does not bypass Windows security policies or unknown Word passwords.
If Python scripts or pip are blocked by company IT, IT approval is required.
