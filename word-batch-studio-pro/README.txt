WORD BATCH STUDIO PRO - PORTABLE

A single-file Windows EXE for batch editing Microsoft Word documents.

Main features:
- Multiple add/remove Find & Replace rule boxes
- Words, sentences, and multi-line paragraph replacement
- Main body, headers, footers, text boxes, footnotes/endnotes/comments, or Everywhere
- Image replacement by image number (#1, #2...) or Alt Text / Title / Shape Name
- .docx, .docm, .doc, .dotx, .dotm and .rtf
- Subfolder processing
- Originals remain untouched
- Edited copies saved to a separate output folder
- Protection options and content-control unlocking on the output copy
- CSV batch report
- Save/load reusable rule sets

Requirement on the target PC:
Microsoft Word must already be installed. No Python installation is required.

Security:
The application does not bypass unknown Word passwords. Protected documents require the correct password if Word requires one.
